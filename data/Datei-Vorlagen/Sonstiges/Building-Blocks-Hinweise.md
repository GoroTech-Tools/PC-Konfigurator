# Word Building Blocks

Die persönliche Word-Datei `Building Blocks.dotx` wird nicht in dieser
Vorlagenbibliothek mitgeliefert. Sie enthält benutzer- und installationsabhängige
Bausteine und liegt standardmäßig unter:

`%APPDATA%\Microsoft\Document Building Blocks\<LCID>\<Office-Version>\Building Blocks.dotx`

## Manuelle Bearbeitung im PC-Konfigurator

Menüeintrag: **Tools → Building Blocks manuell bearbeiten**

Vor dem Öffnen wird eine datierte Sicherung im Unterordner
`_PC-Konfigurator-Backups` der persönlichen Building-Blocks-Datei angelegt.
Die Datei wird direkt in Word zur Bearbeitung geöffnet; es wird kein neues
Dokument aus der Vorlage erzeugt.
