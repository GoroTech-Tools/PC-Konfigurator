# Anwenderprüfung – Kurzcheckliste (5–10 Minuten)

Stand: 2026-05-31

## Ziel

Schneller Praxischeck der **EXE-Variante** durch Kollegium und Teilnehmende,
um früh sichtbar zu machen, ob grundlegende Nutzung stabil funktioniert.

## Schnelltest

- [ ] `PC-Konfigurator.exe` startet
- [ ] GUI ist vollständig sichtbar und bedienbar
- [ ] Eine Schriftart ausgewählt
- [ ] **Nur Office konfigurieren** einmal ausgeführt
- [ ] Keine kritische Fehlermeldung / kein Absturz
- [ ] Log-Eintrag wurde erzeugt

## Optional (wenn Zeit vorhanden)

- [ ] **Vollständige Konfiguration** einmal ausgeführt
- [ ] Explorer-Neustart getestet (falls angeboten/erforderlich)
- [ ] Ergebnis in Word/Excel/Outlook kurz plausibilisiert

## Kurzfeedback (Pflicht)

- Rolle: Kollegium / Teilnehmende
- Windows + Office-Version:
- Ergebnis: OK / Fehler
- Falls Fehler: kurze Beschreibung + Log-Dateiname
